## Calculator_Standare_2

In the second phase of the calculator app's development, 

I enhanced the application by:

1-Adding square root and squaring functions.

2-Adding a screen to save history and display previous results.

3-Adding a button to toggle the number between positive and negative.

4-Adding the ability to delete a single digit.

5-Adding the ability to delete the second number.
